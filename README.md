# Thomas Pugh — personal website

Four static HTML pages and one stylesheet. No dependencies, build step, analytics, or JavaScript.

## Edit
- `index.html`: introduction and contact links
- `projects.html`: selected project cards
- `cv.html`: complete CV text
- `about.html`: biography and brief timeline
- `style.css`: shared warm-charcoal, cream, and brass palette
- `assets/Thomas-Pugh-CV.pdf`: public CV download

Preview: `python3 -m http.server 8765` from this directory.

GitHub Pages: publish the repository root from the `main` branch. `.nojekyll` disables Jekyll processing. All local links are relative.
